## 📖 About the Project

**Exploring Careers in Information Technology** is an educational article series designed to introduce readers to the wide range of career opportunities available in the IT industry.

The series provides clear and practical information about different technology careers, including:

* 💻 Software Engineering
* 🤖 Artificial Intelligence
* 📊 Data Science & Data Analytics
* ☁️ Cloud Computing
* 🔐 Cybersecurity
* 🌐 Networking
* 🎨 UI/UX Design
* 📱 Mobile Application Development
* 🗄️ Database Engineering
* ⚙️ DevOps
* And many more.

The goal is to help students, beginners, and anyone interested in technology understand different IT career paths and make better decisions about their learning and career development.

---

## 🎯 Objectives

This project aims to:

* Introduce major career paths in the IT industry.
* Explain the responsibilities of different IT professionals.
* Identify the technical and soft skills required for each career.
* Explore educational and learning pathways.
* Introduce commonly used technologies and tools.
* Discuss career progression and opportunities.
* Explain challenges within different IT fields.
* Provide guidance for students and beginners.
* Highlight emerging technologies and future career opportunities.

## ✍️ Content Format

Articles are written using Markdown and stored inside the `_posts` directory.

Each Jekyll article follows this structure:

```markdown
---
layout: post
title: "Article Title"
date: 2026-09-05
categories: [IT Careers, Technology]
permalink: /article-url/
---

# Article Title

Article content goes here...
```

## 🖼️ Image Organization

All website images are stored in:

```text
assets/images/
```

Each article can have its own cover image.

For example:

```text
assets/images/
├── home.jpeg
├── career.jpeg
└── software.jpeg
```

Images can be displayed in Markdown using:

```markdown
![Image description]({{ "/assets/images/image-name.jpeg" | relative_url }})
```
